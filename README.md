# かがやきライフタウン大垣2026「まるごと体験ビンゴ」自動化システム・WebビンゴおよびWebマップ

対象イベントは「かがやきライフタウン大垣 秋のつどい」（2026年11月1日、大垣城ホール）です。このリポジトリはClaude Code Webで開発を始め、完成したコードをオンプレミスのLinuxサーバーへ移設します。

本番環境で耐えられるよう、外部設計と内部設計をしっかり行ってください。現時点では、抽選ライン数の純粋関数、9マスの文言・分類、Fastifyのヘルスチェック、テスト、仕様・決定管理文書を含みます。カード発行、認証、DB保存、抽選処理、景品管理、発券、機器API、立体会場マップなどは、これから実装する機能です。

## 最初に確認するファイル

`CLAUDE.md` はClaude Codeへの恒久的な作業指示です。`docs/requirements.md` は提供された仕様書をそのまま保存した正本です。`docs/DECISIONS.md` は仕様書に残る判断事項を追跡します。`docs/IMPLEMENTATION_PLAN.md` は段階的な実装順、`docs/CLAUDE_CODE_FIRST_PROMPT.md` はClaude Code Webに最初に渡すプロンプトです。

## ローカルで動作確認する場合

Node.js 22以降を想定しています。次のコマンドは `server` ディレクトリで実行します。

```sh
npm install
npm test
npm run dev
```

起動したら `http://127.0.0.1:3000/health` を開き、`{"status":"ok","service":"marugoto-bingo","stage":"scaffold"}` が返ることを確認します。ヘルスチェックが返っても、業務機能が実装済みという意味ではありません。

## Claude Code Webから進める

このフォルダーの内容をプライベートなGitリポジトリへ登録し、Claude Code Webでそのリポジトリを開きます。`docs/CLAUDE_CODE_FIRST_PROMPT.md` の指示を最初の依頼として渡してください。仕様書と初期ファイルを一度に貼り付け直す必要はありません。変更後はClaude Codeが作成した差分を確認し、テストが通ることを確認してからコミットします。

## Linuxサーバーへ移す

サーバー上で直接大きな変更を作る運用は避け、リポジトリ、環境変数、永続データを分けます。`deploy/` にあるファイルはひな形で、パスや権限を確認してから使います。

本番公開前に、サーバーOSとNode.js、大学ネットワークの外部公開可否、DNS、HTTPS証明書取得方式、443受信経路、SQLiteバックアップ保存先、会場PCとiPadの接続を実環境で確認する必要があります。
