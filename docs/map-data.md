# 会場マップデータの形式

会場マップは、管理者が「管理」タブの「マップデータ」から、または `scripts/importMap.js --file map.json` でJSONを取り込んで表示します。取り込むとマップ全体が置き換わります。正式な配置、名称、演目だけを登録してください。参考画像から読み取った名称や、`server/config/map.sample.json` のサンプル配置を本番データとして使わないでください。データが未登録のあいだ、来場者マップには会場の床面と「会場配置は運営確認中です」だけが表示されます。

```json
{
  "venue": { "name": "大垣城ホール", "width": 40, "depth": 28, "note": "任意の注記" },
  "places": [
    { "id": "stage", "kind": "stage", "name": "ステージ", "x": 6, "y": 1, "w": 28, "d": 4, "h": 1.2 },
    { "id": "b01", "kind": "booth", "name": "正式名称", "shortName": "短縮名", "category": "体験工房",
      "organizer": "出展団体", "description": "紹介文",
      "x": 4, "y": 13, "w": 4, "d": 3, "h": 1,
      "details": { "hours": "10:00〜12:00", "fee": "無料" } }
  ],
  "programs": [
    { "id": "p01", "stageId": "stage", "title": "演目名", "organizer": "出演団体",
      "startsAt": "2026-11-01T10:00+09:00", "endsAt": "2026-11-01T10:30+09:00", "status": "scheduled" }
  ]
}
```

座標の単位はメートル相当で、会場の左奥が原点です。`x` が右方向、`y` が手前方向、`w` と `d` が床の幅と奥行き、`h` が立体の高さです。画面上の位置は斜め上からの投影で自動計算するので、スクリーンショットのピクセル座標をそのまま使わないでください。

`kind` は `booth`（体験ブース）、`stage`（ステージ、タップでタイムライン）、`facility`（景品交換所、総合案内、入口など。スタンプ対象ではない）、`outdoor`（屋外区画）、`area`（客席などの平面区画、`h` は0）のいずれかです。`shortName` は全体表示のラベルに使い、正式名称は詳細画面に出ます。ラベルが重なる場合は優先度の低いものを隠し、拡大すると表示されます。隠れたブースも、図形のタップ、画面下の「ブースを選ぶ」、キーボード操作で詳細を開けます。

`details` に書ける項目は `hours`（開催時間）、`location`（場所）、`target`（対象）、`requirement`（参加条件）、`capacity`（定員）、`fee`（費用）、`stampCategory`（スタンプ対象種別）だけです。書かなかった項目は表示しません。主催と紹介文が空の場合は「未登録」と表示します。

`programs` の時刻は日本時間（`+09:00` 付き）で書きます。`status` は `scheduled`、`changed`（変更あり）、`cancelled`（中止、取り消し線で表示）のいずれかです。演目がないステージには「ステージ予定は準備中です」と表示します。当日に予定を変更した場合は、JSONを直して再度取り込みます。来場者の画面はマップを開き直したときに最新になります（M12）。
