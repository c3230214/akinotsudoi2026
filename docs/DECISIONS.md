# 未決定事項・決定ログ

状態の意味：`OPEN` は未決定、`PROPOSED` は推奨案を提示した状態、`APPROVED` は決定権を持つ運営担当者が承認した状態、`IMPLEMENTED` は承認済み決定をコードへ反映した状態です。Claude Codeが推奨案を記載しても、自動的に `APPROVED` に変えてはいけません。

## 運営データの未提供事項

玉の手持ち総数・台別初期投入数、正式な会場配置とブース一覧、各ブースの正式名称・主催・紹介文・スタンプ対象種別、ステージ演目と開始終了時刻、紙カードの識別方式、カード⑤の初期達成、同文言マスの割当方式、来場者によるブースQR読取かスタッフ承認か、プリンター型番と用紙幅、カメラ機種と担当者、画像保存期間、会場ネットワーク、サーバーOSと公開設定が未提供または未承認です。名前・時刻・個数を想像で埋めてはいけません。

## 決定ログ

決定事項は次の形式で追記します。

```text
ID:
Status: APPROVED
Decision:
Reason:
Impact:
Approved by:
Date (JST): YYYY-MM-DD
Related tests:
```

決定権限がないClaude Codeや開発者だけで、運営判断が必要な項目を承認済みにしないでください。
